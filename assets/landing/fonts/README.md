# Fonts

- All page text uses Nunito (SIL Open Font License 1.1, see `NUNITO-LICENSE`): the variable font from Google Fonts, instanced to weights 400–800 and subset to basic Latin plus a few punctuation marks.
- The hand-drawn scenes use Excalifont (SIL OFL 1.1, see `EXCALIFONT-LICENSE`), the Latin subset shipped by `@excalidraw/excalidraw@0.18.0`.
